# 屏问 · 屏幕答题助手

一个可自由移动的桌面悬浮窗：实时预览屏幕上的任意区域，一键识别题目并由 AI 作答，给大学生的朋友刷题用的

## 功能特性

- **实时预览**：框选区域后，悬浮窗内以约 8 帧/秒持续显示该区域画面，随时确认程序「看到」的内容。
- **快速作答**：点击「识别并作答」直接使用最新一帧画面，省去「隐藏窗口 + 等待 + 截图」的耗时。
- **收起为桌面形象**：点右上角「—」后主窗口收成桌面右下角的像素小形象，不再只是躲进托盘；单击形象展开，拖动可换位置，右键菜单可直接作答、框选或退出。
- **大肥鱼常驻**：主窗口右下角常驻「大肥鱼」形象，按下/松开分别播放 GitHub 原版「小黄鸭」音效（`Ya1.mp3` / `Ya2.mp3`，原文件未改动）、底部锚定 Q 弹压扁，松开后换「数钱」表情；连续点击依次翻页显示本次/今日/累计、今日记账、模型费率与随机台词，翻完再点收起。切换模型请点模型按钮，与大肥鱼无关。
- **选区隐藏**：框选确认后遮罩立即关闭，不在桌面上留下任何常驻窗口；再次点「区域」才会重新出现。
- **自动作答**：可开启画面变化自动触发（默认关闭，间隔不少于 3 秒，避免误触发消耗额度）。
- **只给答案**：动作行有「只给答案：开/关」按钮，开启后提示词只要求最终答案、不写解析，速度更快也更省 token；开关状态会自动保存。
- **窗口大小可调**：设置里直接填宽度与高度，保存后即时生效；首次打开会按保存尺寸还原，不会被布局撑大，超出屏幕时自动收进可用范围。
- **流式输出**：答案逐字显示，可随时复制。
- **模型选择与计费**：弹出式列表里直接选模型，每项右侧标注固定收费比例（如 `0.08x`、`1.50x`），列表底部可「添加模型」；每次作答按接口返回的 usage 换算本次、今日与累计花费。
- **皮肤系统**：悬浮窗形象由 `skins/<皮肤名>/skin.json` 驱动，改外观无需改代码。

## 启动

```bat
run.bat
```

首次使用如果依赖缺失：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

本仓库不包含 `config.json`（含 API Key，不随仓库分发）。首次运行可从示例复制一份，再在「设置」里填入自己的 Key：

```bat
copy config.example.json config.json
```

## 使用步骤

1. 点击悬浮窗右上角「区域」，拖动鼠标框选题目所在范围；点击「确定」或按 Enter，遮罩立即隐藏。
2. 悬浮窗内会实时显示该区域画面。
3. 点击「识别并作答」，程序使用最新画面完成 OCR 与 AI 请求，答案流式显示。
4. 「识别并作答」右侧的「只给答案」按钮可开关：开启后只输出最终答案，不写解析，响应更快、token 更省；关闭则按设置里的答题风格给出步骤或完整解析。该状态会保存到 `config.json`。
5. 点「设置」选择 AI 预设与模型，填入接口地址与 API Key；模型列表每行右侧是固定收费比例。「窗口大小」可填宽度与高度（380~900 × 500~1000 像素），保存后立即生效。
6. 点「—」收起后，桌面右下角出现像素小形象：单击展开，拖动移动，右键可快速作答/框选/退出；作答时它会切到分析动画，完成后庆祝，出错时显示失败动作。

## AI 接入

- **OCR 模式（默认）**：本地 RapidOCR 先把画面转成文字，再发给模型。适合 DeepSeek、通义千问、智谱、Kimi 等文本模型，Token 消耗低。
- **视觉模式**：截图原图直接交给多模态模型（GPT-4o、qwen-vl 等），对图表、公式题更友好，Token 消耗更高。
- **本地模型**：如 Ollama，接口地址填 `http://127.0.0.1:11434/v1`，Key 可留空。

速度方面做了三项优化：实时帧缓存（作答无需重新截图）、启动时预热 OCR 模型、流式返回答案。实际延迟主要取决于所选模型的响应速度。

## 模型与计费

- **选择模型**：主窗口状态栏上方与设置界面都有模型按钮，点开是弹出列表：左边模型名、右边固定收费比例（如 `Qwen3.8 Flash 0.08x`、`Qwen3.8 Max 1.50x`）；支持图片的模型标注「视觉」。
- **只保留可用且够快的模型**：清单按百炼接口 `/v1/models` 与真实请求逐项验证。已删除持续 `429` 不可用的 `qwen-turbo`、只返回空内容的 `deepseek-v4.1-flash`，以及未开通的 MiniMax、Step、MiMo 等。剩余 8 个模型实测首字延迟均小于 1 秒：
  `qwen-flash`、`qwen3.5-flash`、`qwen3.6-flash`、`qwen3.7-flash`、`qwen3.8-flash`、`qwen-plus`、`qwen3-vl-plus`（视觉）、`qwen3.8-max`。
- **关闭 thinking 提速**：Qwen3 系列默认先「思考」，首字可等 7~49 秒；请求时对 `qwen3*` 自动带 `extra_body={"enable_thinking": false}`，实测降到 0.4~0.9 秒。
- **收费比例固定**：比例由程序内置（`1.00x = ¥10 / 百万 tokens` 的参考基准），界面只展示、不提供改价入口；厂商调价时更新 `app/core/models.py` 即可。
- **添加模型**：列表底部「添加模型」只需填写 API 里的 model 名称，未收录的模型按固定 `1.00x` 参考比例计费，不能自行改价。
- **计费方式**：请求时向接口申请 `stream_options.include_usage`，按返回的 `prompt_tokens` / `completion_tokens` 与目录固定单价换算；接口不返回 usage 时按文本长度估算，并在界面上标注「估算」。
- **显示位置**：悬浮窗底部显示「本次 · 今日 · 累计」与记账 token 数，悬停可看当前模型与单价；收起成桌面形象后，作答完成会在形象头顶弹出气泡显示本次花费、今日与累计。
- **数据存储**：累计统计保存在 `config.json` 的 `billing` 字段，跨天自动把「今日」归零；删除该字段即可重置统计。

## 桌面形象（素材与替换）

主窗口右下角常驻「大肥鱼」形象（`assets/whale/dsniang.png`，来自 dsh-whale-widget-plus 素材）：按下播放 GitHub 原版「小黄鸭」按压音效 `Ya1.mp3`，松开播放 `Ya2.mp3`（两个文件均从插件 `assets/` 原样复制、未做任何转码或修改），形象以脚底为锚点 Q 弹压扁，松开回弹并换成「数钱」表情（`react_money.png`）；连续点击按队列翻页——本次/今日/累计 → 今日记账 → 模型费率 → 随机台词，翻完再点收起，气泡 6.5 秒后自动关闭、点击可立刻关闭。

形象、音效和气泡全部可通过皮肤里的 `mascot` 段替换（相对路径以皮肤目录为基准，找不到时回落到内置素材）：

```json
"mascot": {
  "size": 78,
  "idle_image": "../../assets/whale/dsniang.png",
  "react_image": "../../assets/whale/react_money.png",
  "press_sound": "../../assets/whale/Ya1.mp3",
  "release_sound": "../../assets/whale/Ya2.mp3",
  "bubble_close_ms": 6500,
  "lines": ["大肥鱼在盯着钱包呢～", "点一下，鱼就少一口饭"]
}
```

收起后的形象使用 `assets/aemeath/spritesheet.webp`（精灵表 1536×3120，8 列 × 15 行，单元 192×208）。渲染方式与 floating-pet-kit 一致：0.5 倍呈现（96×104）、180ms 逐帧、像素化缩放、悬停挥手、待机随机小动作（12~38 秒一次）。

状态对应关系：

| 程序状态 | 精灵行 |
|---|---|
| 待机 / 悬停挥手 | idle / waving |
| 正在识别或 AI 作答 | analyzing |
| 作答完成 | celebrating（2.6 秒后回待机） |
| 出错 | failed（2.6 秒后回待机） |

换成自己的素材时，只要保持「8 列 × 15 行、单元 192×208、行顺序不变」，替换 `spritesheet.webp` 即可；形象位置保存在 `config.json` 的 `pet` 字段。

## 更换悬浮窗形象（设计开口）

悬浮窗全部外观由 `skins/<皮肤名>/skin.json` 驱动：

```json
{
  "name": "暗夜",
  "title": "屏问",
  "avatar_text": "◈",
  "avatar_image": "",
  "colors": {
    "bg": "#1b1d24",
    "panel": "#23262f",
    "accent": "#6e9bff",
    "text": "#e9ecf4",
    "muted": "#939cae",
    "border": "#323745"
  },
  "bg_alpha": 242,
  "radius": 14,
  "font_family": "Microsoft YaHei UI",
  "font_size": 13
}
```

新增形象：

1. 复制 `skins/default` 为 `skins/你的皮肤名`；
2. 修改颜色、圆角、字体、字号；
3. 使用图片头像时，把图片放入该皮肤目录，填写 `"avatar_image": "avatar.png"`；
4. 需要更细的样式控制时，在 `extra_qss` 中追加 Qt 样式表；
5. 重启程序，在「设置 → 悬浮窗皮肤」中切换。

## 目录结构

```
app/
  main.py              入口、托盘图标、OCR 预热
  config.py            配置读写（config.json）
  core/
    live.py            实时区域捕获（mss 后台线程、画面变化检测）
    capture.py         静态截图与 PNG 编码
    ocr.py             RapidOCR 识别与分行重组
    ai.py              OpenAI 兼容接口流式作答（申请 usage）
    worker.py          OCR + AI 后台线程、token 用量与估算
    models.py          百炼可用模型与固定收费比例
    billing.py         费用换算、今日/累计统计
    sound.py           按压/松开音效播放（WAV 用 winsound，MP3 用 miniaudio）
  ui/
    hud.py             悬浮窗（实时预览、作答、计费展示、大肥鱼形象、自动模式）
    mascot.py          右下角大肥鱼（按下反馈、数钱表情）
    pet.py             收起后的桌面像素形象（精灵动画、拖动、费用气泡）
    model_menu.py      模型列表弹层（名称 + 固定比例 + 添加模型）
    region_picker.py   区域选择遮罩
    settings_dialog.py 设置界面（预设、模型、模式与外观）
    skin.py            皮肤加载与样式生成
    widgets.py         可拖动标题栏等通用控件
assets/aemeath/        桌面形象精灵表（本地自备，不随仓库分发）
assets/whale/          主窗口右下角的大肥鱼形象（本地自备，不随仓库分发）
skins/                 皮肤目录
config.example.json    配置示例（复制为 config.json 后填入自己的 Key）
config.json            本地配置，保存区域、窗口/形象位置、API 与计费统计（已 gitignore）
```

本仓库只包含代码与皮肤配置。以下两类美术素材**不随仓库分发**，`.gitignore` 已排除：

| 目录 | 内容 | 来源与状态 |
|---|---|---|
| `assets/whale/` | 大肥鱼图片、按压/松开音效 | 取自 `dsh-whale-widget-plus`。该仓库代码为 MIT，但其 `PROVENANCE.md` 明确 `assets/**` **不适用 MIT、不授予再许可**，仅按原样随插件运行使用，因此不宜再分发。 |
| `assets/aemeath/` | 桌面像素形象精灵表 | 来自本地 `floating-pet-kit`，权利状态无法确认。 |

缺失素材时程序不会崩溃：右下角大肥鱼留空、收起后的桌面形象显示为圆角占位块、音效静默跳过。想恢复这些效果，请自行准备图片与音效，按上面的 `mascot` 段或 `spritesheet.webp` 规格放入对应目录。

如果你要公开展示带大肥鱼的截图，建议先向素材作者确认，或改用自制形象（`skins/<皮肤名>/skin.json` 的 `mascot` 段指向自己的文件即可）。

代码部分可自行选择开源许可；若后续添加 `LICENSE`，建议注明「代码按该许可授权，`assets/` 素材不在授权范围内」。

## 已知限制

- 区域选择限制在单块屏幕内，不支持跨屏框选。
- 受系统保护的内容（部分播放器、独占全屏游戏）无法截取。
- 公式以 LaTeX 文本形式显示，未做公式渲染。
- 实时预览默认约 8 帧/秒；提高帧率会增加 CPU 占用，可在 `app/core/live.py` 的 `LiveCapture(120, self)` 中调整间隔（毫秒）。
